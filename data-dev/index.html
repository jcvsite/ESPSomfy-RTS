How it works

Per room: Auto picks the strongest radio that heard a linked remote (≥ −85 dBm). Manual locks that room to This unit or a Slave. If the chosen Slave is offline, the next-best online radio is used, or this Router. Link the physical remote on each shade so Auto can identify it.
